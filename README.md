# Kimi and Moonshot AI on AWS

A collection of code samples and notebooks to get started with models from Kimi / Moonshot AI on AWS. Open a PR if you would like to contribute! :twisted_rightwards_arrows:

## Kimi Models on Amazon Bedrock

Amazon Bedrock now supports Kimi K3! See the [example notebook](Kimi-On-Amazon-Bedrock/Kimi%20K3%20on%20Amazon%20Bedrock.ipynb) for a guide on how to get started.

Older Kimi models are also available on Amazon Bedrock - see the [Moonshot AI model cards](https://docs.aws.amazon.com/bedrock/latest/userguide/model-cards-moonshot-ai.html) in the [Amazon Bedrock User Guide](https://docs.aws.amazon.com/bedrock/latest/userguide/what-is-bedrock.html) for more information on currently supported models, API endpoints, and features.

## Kimi API Platform on AWS Marketplace

You can also use the [Kimi API Platform on AWS Marketplace](https://aws.amazon.com/marketplace/pp/prodview-rfjb2elzc5jp4), for direct access to the latest Kimi models and features operated by Moonshot AI.

## Deploying Kimi Models Yourself

Builders looking for more customization may also be interested to explore hosting Kimi on your own AWS infrastructure. Check out the following examples to get started:

- Deploying Kimi K3 on Amazon SageMaker HyperPod and Amazon EKS: [blog](https://aws.amazon.com/blogs/machine-learning/deploying-kimi-k3-on-amazon-sagemaker-hyperpod-and-amazon-eks/) and [code sample](https://github.com/aws-samples/sagemaker-genai-hosting-examples/blob/main/SageMakerHyperpod/kimi-k3/kimi-k3.yaml)
- Deploy Kimi K2.5 on SageMaker AI: [example notebook](https://github.com/aws-samples/sagemaker-genai-hosting-examples/blob/main/01-models/Kimi/LMI/kimi-k2.5.ipynb)
