# Indic Document Intelligence with Kimi K3 on Amazon Bedrock

This sample explores how Kimi K3 can be applied to analyze and extract documents, including scanned or photographed images of documents in Indic languages like Hindi.

To get started:

1. Follow the prerequisite setup in the [repository README](../../../README.md#prerequisites)
2. Open the Python notebook, [Indic Document Intelligence.ipynb](Indic%20Document%20Intelligence.ipynb)
